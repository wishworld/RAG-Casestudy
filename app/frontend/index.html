8

      

        
Keyword Search

        
PostgreSQL full-text search. Takes its input from Stage 6's normalized output. No embedding call - exact/lexical token matching via tsvector + GIN index. Complementary to Stage 7: strong on exact codes/terms, weak on paraphrases.

9

      

        
Hybrid Search (RRF fusion)

        
Fuses Stage 7 + Stage 8. Runs semantic and keyword search in parallel, then combines both ranked lists via Reciprocal Rank Fusion - no raw-score comparison, just rank position.

      

    

    
⚠ Results are from a different query - re-run to refresh

10

      

        
No-Answer Detection

        
Checks Stage 9's last result against TWO bars - passes if EITHER clears: RRF score (both sources agree) OR raw similarity (confident even if only one source found it). Thresholds are small-sample starting guesses - adjust and re-check freely.

      

    

    

      
      
      
      
      
    

    

  


  

    

      
11

      

        
Context Construction

        
Prepares Stage 9's surviving chunks for the LLM prompt: dedup exact repeats, merge chunks that are adjacent in the same document into one coherent block, restore document reading order (not RRF rank order), trim to a token budget, then tag each with a citation marker [S1], [S2]...

12

      

        
Answer Generation (qwen2.5:7b)

        
Takes its question from Stage 6's normalized output, plus Stage 11's context blocks. Sends a grounded prompt to the local LLM and shows the answer. The LLM does not search anything - Stages 6-11 already found the evidence.

RAG Evaluation (Stage 13)

  
Runs a batch of questions through the FULL pipeline (Stages 6-12, including the LLM) and scores retrieval, no-answer detection, and answer quality automatically - instead of eyeballing results one at a time.
