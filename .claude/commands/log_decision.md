You are in DECISION LOGGING MODE.

Your job: capture decisions from this conversation (or a single decision passed as text) and append them to `docs/decisions-log.md`.

A "decision" is any moment where a direction was chosen, a trade-off was resolved, something was scoped in/out, or a constraint was accepted. Not opinions, not questions — only things that were actually decided.

## Input

`$ARGUMENTS` controls the mode:

- **No arguments** — scan the full conversation and extract every decision made.
- **Text passed** (e.g., `/log_decision We chose X over Y because cost`) — log that single decision exactly as described. Do not invent rationale.

## Step 1 — Extract decisions

For each decision, capture:

| Field | What to fill |
|-------|-------------|
| **Topic** | Short label (2-5 words) — e.g., "Auth method", "Scope cut", "Stack choice" |
| **Decision** | What was decided, one sentence |
| **Rationale** | Why — the actual reason given in conversation. If no reason was given, write "Not stated". Never invent a reason. |
| **Status** | `Locked` (final), `Parked` (deferred), or `Open` (tentative) |

If no decisions can be found, say: "No decisions found in this conversation. Pass a decision as text: `/log_decision [what] because [why]`"

## Step 2 — Read existing log

Read `docs/decisions-log.md` if it exists.
- If it exists: find the last entry number to continue the sequence.
- If it does not exist: create it fresh with the header below.

## Step 3 — Append to log

File format for `docs/decisions-log.md`:

```markdown
# Decisions Log

> Auto-generated by /log_decision. One row per decision, newest at the bottom.
> Status: Locked = final | Parked = deferred | Open = tentative

| # | Date | Topic | Decision | Rationale | Status |
|---|------|-------|----------|-----------|--------|
```

Append new rows. Never delete or overwrite existing rows. Date = today's date in `YYYY-MM-DD`.

## Step 4 — Confirm

After writing, print:

```
Decisions logged to docs/decisions-log.md

Added: [N] new decision(s)
  - [Topic]: [Decision] ([Status])
  ...

Total decisions in log: [total count]
```

## Rules

1. **Never invent rationale.** If the reason was not stated, write "Not stated".
2. **Never delete existing rows.** Only append.
3. **One row per decision.** Do not merge separate decisions.
4. **Use today's date** — never leave date blank.
5. **Short topics.** 2-5 words max. This is for scanning, not reading.
6. **If status is unclear**, default to `Open`.
